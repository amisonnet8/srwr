R10.5：英語を既定にし、日本語に切り替えられるようにする／時刻を UTC で持つ

画面の配置・色・振る舞いは、確定したデザインのまま変えません。変えるのは文言（英語を既定、日本語に切り替え）と、時刻の持ち方・見せ方だけです。SRWR_LANG=ja にすると、今までの日本語と同じ出力になります（テストで確かめます）。

作るもの

  • CLI の出力・usage・エラー文、VSCode と Vim の画面の文言を、英語が既定、日本語に切り替え
  • テープの時刻を UTC で書く。表示は TZ に従う
  • docs/ を英語既定にして、日本語版を _ja.md に
  • 画面の基準を、英語と日本語の両方で持ち、両方で比べる

決めること（推奨案）

項目推奨案理由
切り替え方CLI と Vim は環境変数 SRWR_LANG（ja で始まれば日本語、それ以外・未設定は英語）。VSCode は VSCode の表示言語（日本語の言語パックなら日本語）。LANG からは推測しないコマンド名は VSCode の表示言語にしか従えない。「何も設定しなければ英語」を守る
英語だけにするものMCP のツールの説明とエラー文、hook の注記、表示サーバーのエラー文。人に見せるもの（テープが無い・版の不一致など）は、クライアントがエラーコードから自分の言語の文を作る読むのは AI か開発者。プロトコルは変えない
時刻の持ち方テープの startedAt・ts、表示サーバーの updatedAt、テープID は UTC（…Z）。古い +09:00 のテープもそのまま読める共有したとき、どの機械でも同じ意味になる
時刻の見せ方その機械の時間帯（TZ）に直して見せる。srwr tapes は英語 Oct 03 17:12・日本語 10/03 17:12。Vim の一覧と VSCode のテープ選びは両言語とも 2026-10-03 17:12年も見えて並べやすい形を残す
docsdocs/名前.md を英語、docs/名前_ja.md を日本語。先頭に相手の言語へのリンク。README.md は R11 で同じ形に人間の決定
