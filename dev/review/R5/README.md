# R5 UIゲート：Vim クライアント srwr-view.vim

見るのは `index.html`（画像を埋め込んだ1ファイル。ブラウザで直接開ける）。

- **新しい画面はない。** 確定済みのデザイン（`handoff/design/images/vim/`）を、そのまま作る
- 決めてほしいのは、前の実装から持ち越した課題3件の直し方（推奨案はどれも A）
  1. 範囲が画面の下端に近いと隠れる → 差し込んだあとの行番号で判定し、見えなければ中央へ
  2. ライブで「LIVE に戻る」が切れる → 「（閉じる：…）」は全部収まるときだけ出す
  3. 理由の行の行番号 → 自前の番号（行頭の仮想テキスト）にする（確認だけ）
- 直した後の画像（`fix1-after_*`・`fix2-after_*`）は、確定画像の複製を直した案。下の数行の色は省いた描き
