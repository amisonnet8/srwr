# srwr の設計の全体像

*[English](overview.md) | **日本語***

**読者**：srwr の作りを知りたい人、開発に加わる人。使い方は [reference の文書](../reference/cli_ja.md)、判断の理由は [decisions.md](decisions_ja.md)。

## srwr とは

AI エージェントに、srwr の道具（`look`・`edit`・`new`、任意の `session`）でファイルを編集させ、一つ一つの操作を `why`（理由）つきで**テープ**に記録し、エディタで**コマ送りで再生**する道具。`why` と範囲のコードを一緒に見せることで、人間が AI の作業を理解できるようにする。

## 設計の前提

次の5つが、作りの出発点になっている。

| 前提 | 設計への影響 |
|---|---|
| `why` 付きの操作列は、人が AI の作業を理解できる。`why` がないと、操作の列も diff も読みにくい | 編集は、`why` を必須にした道具を通す |
| 理解の中心は `why`。選択範囲のコードは、イメージを具体にする補助 | 画面は、理由の行と範囲を、同じ場所で見せる |
| エディタで見ると、構文ハイライト・前後の文脈・言語機能を任せられる | 見る場所はエディタ（VSCode と Vim）にする |
| AI 以外の変更（外部変更）は、ラベルだけでは分からない。中身が見えれば分かる | 外部変更は、左右に並べた差分で見せる |
| 再生は、1コマずつ読み進める使い方が中心。ライブは AI の実際の速さでよい | 見る操作は、コマ送りだけにする |

## 基本方針

### 境界は「コマの列」

- 見た目と振る舞いは固定している（[vscode.md](../reference/vscode_ja.md)・[vim.md](../reference/vim_ja.md)）
- UI と裏側の境界は **「コマの列」**（[protocol.md](../reference/protocol_ja.md)）。表示サーバーが作り、エディタに渡す
- 裏側の変更（テープの形式、セッション、記録しないファイルなど）は、表示サーバーの中で吸収し、エディタ側には波及させない
- 表示の部品を変えるときは、VSCode と Vim の両方の画面の仕様を、先に直す

### 守る線

| 線 | 内容 |
|---|---|
| テープが唯一の記録 | 再生はテープだけで完全に再現できる。実ファイルは、「最後の差分」の比較にだけ使う（ライブもテープだけを読む） |
| 書く・組み立てる・描くを分ける | テープを**書く**のは `srwr mcp`・`srwr hook`。テープを**読んでコマを組み立てる**のは `srwr view-server`。エディタ側は**描くだけ**で、テープを直接読まない。テープにも実ファイルにも書かない |
| Go とエディタの境界はプロトコル | テープの形式は Go の中だけの約束。エディタとの約束は表示サーバーのプロトコル。変えるときは、先に文書を直し、サーバーと両方のクライアントを同時に直す |
| 編集は srwr の道具を通す | `look`・`edit`・`new`。変えるたびに、変えた範囲がテープに残るので、「見て、変える」を再生できる。厳格モードでは、エージェント自身の Edit・Write を禁止する |
| `why` は必須（srwr 経由の編集では） | 入力スキーマとサーバーの両方で検査する |
| 依存を増やさない | Go は外部依存ゼロ（MCP も表示サーバーも自前の JSON-RPC）。VSCode 拡張はランタイム依存ゼロ（`tsc` のみ）。Vim は他のプラグインに頼らない |

### 見る場所はエディタ、共有はテープ

- 見る場所は **VSCode（srwr-view）と Vim（srwr-view.vim）**。Markdown や HTML への書き出しはしない
- 共有したいときは、テープそのものを渡す。受け取った人は自分のエディタで開く

### Vim に対応する理由

- **ターミナルだけで見られるようにするため。** srwr を使うのは、AI エージェント（Claude Code など）を入れた開発環境。AI エージェントをターミナルで動かしている人が、同じターミナルからテープを再生できるようにする
- **Vim を対象にし、Neovim は対象にしない。** Neovim は使う人しか入れていないので、「ターミナルで誰でも見られる」という目的に合わない
- AI エージェントを入れる開発環境は新しいので、**Vim 9.0.0784 以上**を前提にする。古い Vim に合わせた分岐は持たない
- **利用者にプラグインのインストールを求めない。** `srwr view` が、バイナリに埋め込んだ Vim スクリプトを読み込んで Vim を起動する
- 構文ハイライトは Vim に任せる

## 構成

```
                           ┌──────────────────────────────┐
AI ──look / edit / new───▶│ srwr mcp                     │──▶ 実ファイル
AI ──Read/Bash/Grep/Edit─▶│ srwr hook（Claude Code hook）│
                           └──────────────┬───────────────┘
                                          │ ロックを取って追記
                                          ▼
                        .srwr/tapes/<id>.tape.jsonl（1セッション＝1本。
                                       閉じると .tape.jsonl.gz）
                                          │ 読むだけ
                                          ▼
                           ┌──────────────────────────────┐
                           │ srwr view-server（Go）       │
                           │ テープの読み込み・コマの組み立て│
                           │ ・各コマの文書の状態・最後の差分│
                           │ ・ライブの監視                 │
                           └───────┬──────────────┬───────┘
                 JSON-RPC（stdio）  │              │  JSON-RPC（stdio）
                                   ▼              ▼
                        srwr-view（VSCode）   srwr-view.vim（Vim）
                        描くだけ              描くだけ（srwr view で起動）
```

| 部品 | 中身 |
|---|---|
| **`srwr`**（Go の単一バイナリ） | サブコマンド `mcp`・`hook`・`view-server`・`view`・`init`・`tapes`・`trace`（[cli.md](../reference/cli_ja.md)） |
| **テープ** | 追記のみの JSONL。1セッション＝1本で、閉じると圧縮する。AI が `session` で付けた題を持つことがある（[tape.md](../reference/tape_ja.md)） |
| **srwr-view**（VSCode 拡張） | ライブ・リプレイ・コマ送り・差分のコマの**表示** |
| **srwr-view.vim**（Vim スクリプト） | 同じ UI を Vim で表示する。`srwr` のバイナリに埋め込む |

## 設計に含まれるほかのこと

- **見せるコマの選択。** look・edit・external・failure を、両方のエディタで ON/OFF できる。絞るのは表示サーバー（[protocol.md](../reference/protocol_ja.md)）。失敗した呼び出しは `failure` としてテープにあり、頼まれたときだけ、赤で見せる
- **テープの題。** AI は、題と理由をつけて新しいテープを始められる（`session`）。題を出すのは、テープの一覧だけ
- **コミットとテープを結ぶ。** `srwr trace` が、差分のテキストを読み、追加された行を書いた操作と `why` を言う。その操作を、再生できるテープに切り出すこともできる。git は動かさず、テープは変えない
- **英語が既定で、日本語に切り替える。テープは UTC、画面は手元の時刻**（[settings.md](../reference/settings_ja.md)）
