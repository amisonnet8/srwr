look / edit / replace / new：画面の名前のゲート

色・形・並び・差分の見せ方は今のまま。変わるのは、操作の名前の文字、種類の ON/OFF の分け方、Vim のキーです。画像は dark と light の両方です。

作るもの

  • AI のツールが look（見る）・edit（直す。lookのトークンでも、ファイル＋範囲＋expect でも）・replace（複数箇所の置換。旧 sub）・new になる
  • 画面の名前も同じ4つ。旧：select→look、replace→edit、sub→replace
  • 種類の ON/OFF は4つ：look／edit（edit・replace・new）／external／failure
  • Vim のキー：tl look、te edit、tx external、tf failure（今の te は external）

新しく決めること（推奨が先頭）

  1. ON/OFF の分け方：4つ（推奨）／別々に切る5つ
  2. Vim のキー：tl・te・tx・tf（推奨）／今のキーのまま意味だけ読み替える
  3. 日本語の画面の名前：look・edit・replace・new のまま（推奨）／日本語に訳す
