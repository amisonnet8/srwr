# R10.5 ゲート：英語を既定にする・時刻を UTC で持つ

画面の配置・色・振る舞いは確定デザインのまま。変えるのは文言と時刻だけ。`SRWR_LANG=ja` なら今までの日本語と同じ出力（テストで確かめる）。ブラウザで `index.html` を開くと、画像と対訳表が1枚で見える。

## 作るもの
- CLI・VSCode・Vim の文言を英語既定、日本語に切り替え
- テープの時刻を UTC で書き、表示は `TZ` に従う
- `docs/` を英語既定にして、日本語版を `_ja.md` に
- 画面の基準を英語と日本語の両方で持つ

## 決めること（推奨案）
- **切り替え方**：CLI と Vim は環境変数 `SRWR_LANG`（`ja` で始まれば日本語、それ以外・未設定は英語）。VSCode は VSCode の表示言語（日本語の言語パックなら日本語）。`LANG` からは推測しない（コマンド名は VSCode の表示言語にしか従えない。「何も設定しなければ英語」を守る）
- **英語だけにするもの**：MCP のツールの説明とエラー文、hook の注記、表示サーバーのエラー文。人に見せるもの（テープが無い・版の不一致など）は、クライアントがエラーコードから自分の言語の文を作る（読むのは AI か開発者。プロトコルは変えない）
- **時刻の持ち方**：テープの `startedAt`・`ts`、表示サーバーの `updatedAt`、**テープID** は UTC（`…Z`）。古い `+09:00` のテープもそのまま読める。ファイル名の日時（`20261003-0812-k3f9` の `0812`）も UTC で、`Z` は付けない。日本の機械では、一覧の `17:12` と 9 時間ずれて見える（ファイル名は一意な名前で、時刻は一覧で見る）。今あるテープの名前は変えない（共有したとき、どの機械でも同じ意味になる）
- **時刻の見せ方**：その機械の時間帯（`TZ`）に直して見せる。`srwr tapes` は英語 `Oct 03 17:12`・日本語 `10/03 17:12`。Vim の一覧と VSCode のテープ選びは両言語とも `2026-10-03 17:12`（年も見えて並べやすい形を残す）
- **docs**：docs の各文書は、英語を `名前.md`、日本語を `名前_ja.md`。先頭に相手の言語へのリンク。`README.md` は R12 で同じ形に（人間の決定）
