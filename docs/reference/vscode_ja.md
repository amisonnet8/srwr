# VSCode（srwr-view）

*[English](vscode.md) | **日本語***

**読者**：VSCode でテープを見る人。

VSCode の拡張 **srwr-view** で、AI の操作をコマ送りで見る。見た目と振る舞いは固定されている。見るのは**コマ送りだけ**で、自動再生はない。

## 使い始める

1. `srwr` のバイナリを入れる（[cli.md](cli_ja.md)）。拡張はこれを起動して、テープを読む
2. 拡張 srwr-view を入れる（`.vsix`）
3. 作業場を VSCode で開く。左端の「srwr」→「操作一覧」から、「テープを開く」か「ライブ視聴を開始」

- `srwr` の場所は設定 `srwr.path`（既定は `srwr`＝PATH から探す）。見つからないときは、入れ方と「設定を開く」ボタンつきで案内する。バージョン（`protocolVersion`）が合わないときは、どちらかを更新するよう案内する
- 設定は `srwr.path` だけ。見た目の設定はない
- 表示サーバー（`srwr view-server`）は、最初に必要になったときに起動する。作業場ごとに1つ
- 拡張は、テープも実ファイルも書き込まない。鍵（`.srwr/key`）も読まない
- 古い形式のテープも読める

## 言語と時刻

- 拡張が出す文言は**英語**で、**VSCode の表示言語が日本語のときは日本語**（日本語の言語パックを入れる）。コマンドパレットのコマンド名も同じ言語になる。srwr の側の設定はない
- テープ選びの時刻は、その機械の時間帯で見せる。テープには UTC で持つ

## 画面の仕様

### 1. 色

**look は青、ファイルを変えたもの（edit・replace・new、外部変更）は橙。** 理由の行は濃い色に白の太字、範囲は同じ色の薄い色。

| 部分 | look（青） | edit など、ファイルを変えるもの（橙） |
|---|---|---|
| 理由（why）の行 | 背景 `#0b61a4`、白の太字 | 背景 `#b45f06`、白の太字 |
| 範囲 | 暗いテーマ `#1d3a5c`／明るいテーマ `#cfe3fb` | 暗いテーマ `#583c27`／明るいテーマ `#fde3c8` |

- 理由の行の色は、どちらのテーマでも同じ（白い太字の読みやすさを保つ）。範囲だけテーマで替える
- **失敗**（AI がエラーを受け取った `look`・`edit`・`replace`・`new`）は**赤**：理由の行は `#d50000`（白の太字。どちらのテーマでも同じ）、操作一覧の丸は `srwr.failureForeground`（拡張の色。dark `#ff3b30`、light `#d50000`）。橙との見分けは、記号 `✖` と文字 `失敗` でも付ける
- 外部変更（srwr の外での変更）は、操作一覧の丸だけ**紫**（`charts.purple`）にする。範囲の色は、差分の見せ方に従う（下の 3）

### 2. look と edit のコマ

- テープを仮想ドキュメント（`srwr-replay:/<テープ名>/<ファイル>`）に展開して見せる。実ファイルには触れない。元ファイルの拡張子を保つので、構文ハイライトが効く
- **範囲の直前に、理由（`why`）の行を実際に差し込む。** 青か橙の背景に白の太字。長い理由は、幅（表示の幅100）で何行かに折り返し、全文を出す。2行目からは字下げする。`why` が `null` のコマは、理由の行を出さない（範囲の色だけ）
- 範囲の行を、薄い色で塗る（空範囲は塗らない）
- コマを移るたびに差し替え、理由の行は常に今のコマの分だけ
- edit は、**書き換えたあとの内容を、最初から橙で見せる**（赤→緑の動きはない）
- **行番号**：理由の行を差し込むと、標準の行番号が合わなくなる。そのため、理由の行があるコマでは標準の行番号を消し、**実ファイルどおりの番号**を本文の左端に出す（理由の行は空白）。理由の行がないコマ・差分のコマは、標準の行番号

### 3. 差分のコマ（外部変更・最後の差分）

- `external`（テープの途中の、srwr の外での変更）と `final`（録画のあとの、今のファイルとの差分）は、**左右2つのエディタ**で見せる。左＝変更前、右＝変更後
- **変わった行だけを塗る：左は青、右は橙。** 変わった行は、拡張が前後を行で比べて決める。標準の diff 画面は使わない（標準の色を替えられないため）。行をそろえる空白行や、左右のスクロールの連動はない
- 最初に変わった行が、画面の上から**3割ぐらい**に来るようにスクロールする。片方に変わった行がなければ（足しただけ、消しただけ）、もう片方の行に合わせる
- 見出しは、左のタブに出す
  - 「前 ⚠ srwrの外で変更：main.go」
  - 「前 ⚠ 録画のあとで変更（今のファイルとの差分）：main.go」
  - 今は存在しないファイルは、「録画のあとで変更」の見出しに「…（今は存在しない）」。外部変更で消されたファイルは、「srwrの外で変更」の見出しに「…（削除）」。右のタブは「後 main.go」
- ふつうのコマに戻ると、右側のエディタを閉じる。**行き来しても、タブは増えない**
- 1回の変更につき1コマ。変更がなければ出さない

### 3a. replace のコマ

- `replace` は、複数のファイルで文字列を一度に置き換える。**変わったファイルごとに1コマ**（テープでは `replace`）で、`external` のコマと同じく**左右2つのエディタ**で見せる：左が変更前、右が変更後で、変わった行だけを塗る（左は青、右は橙）。1つのファイルに場所がいくつあっても、1コマ
- **`why` は、変わった行のまとまりごとの直前の帯に出す**（まとまり＝変わった行が続く塊。間に変わらない行が1行でもあれば別のまとまり）。左右で行がそろうよう、同じ行数にする。VSCode にはタブとエディタの間の帯がないので、どちらの文書もその行を中に持つ：右は `why`（橙に白の太字。ふつうの `why` と同じく折り返す）、左は青の空の行。どのまとまりにも `why` の全文を出すので、変更がファイルのどこにあっても、変更のすぐ上で読める。実ファイルどおりの行番号を出し、帯の行には番号がない。最初の帯が、各エディタの上から約30%に来る
- 左のタブは「前 ⚠ replace：main.go」、右のタブは「後 main.go」
- 操作一覧の行は `番号  replace  ファイル（N か所）`（英語の画面は `(N hits)`）。丸は橙、説明は `why`。`replace` のコマは `edit` と一緒に表示の ON/OFF が切り替わる（下の 8）
- 帯の文字は左寄せ（VSCode の拡張は、エディタの幅が分からず、中央に寄せられない。Vim は窓の中央に寄せる）

### 3a2. new のコマ

- `new` は、ファイルを作る（テープでは `new`。[mcp.md](mcp_ja.md#new)）。`edit` のコマと同じく**1枚のエディタ**で見せる：ファイル全体を橙で塗り、上の橙の行に `why`。左右には分けない（左が空になるため）
- 操作一覧の行は `番号  new  ファイル:範囲`（ファイル全体なら `1-5`）。丸は橙、説明は `why`。`new` のコマは `edit` と一緒に表示の ON/OFF が切り替わる（下の 8）

### 3b. 失敗のコマ

- 失敗のコマには、開くファイルがない（失敗は、絶対パス・記録しないファイル・入力の誤りのことが多い）。**説明の仮想ドキュメント**として見せる：赤い行 `✖ look が失敗しました (invalid_range)`（白の太字。`edit` なら `edit が失敗しました`）、続けてエラー文、`why`・`tool`・`range`（`look` に渡された範囲。`edit` にはない）・`file`（伏せたときは `(not shown)`）。エディタのタブの名前は `失敗: look (invalid_range)`
- 一覧に出るのは、`failure` を表示しているときだけ（下の 8）

### 4. 操作一覧（左のパネル）

- 左端の「srwr」→「操作一覧」。コマを、**記録された順に、上から1、2、3…と並べる**。番号は、下のバーの位置（5/7）と同じ。親子の字下げはしない
- 各行：`番号  種類  ファイル:範囲`（`replace` のコマは `ファイル:範囲` の代わりに `ファイル（N か所）`）（`37`・`39-41`。空の範囲は `12の前`）、説明は `why`。先頭の丸の色で見分ける：look＝青、edit・replace・new＝橙、外部変更・録画後＝紫、失敗＝赤。種類の名前は、日本語の画面では `look`・`edit`・`replace`・`new`・`外部変更`・`録画後`・`失敗`（英語の画面では `look`・`edit`・`replace`・`new`・`external`・`final`・`failure`）。失敗の行は、`ファイル:範囲` の代わりにエラーコード（`invalid_range`）を出す
- クリックで、そのコマへ移る。今のコマの行を選択状態にする
- 右上の ☓ で、テープ（またはライブ）を閉じる

### 5. 下のバー（ステータスバー）

- **「戻る」「進む」と位置（5/7）が、いつも出る。** 行けない側（最初のコマの戻る、最後のコマの進む）は薄くする（消さない）
- 再生・速度・実時間／等間隔のボタンはない
- 右端の ☓ で閉じる

### 6. ライブ

- **録画と同じ画面**（理由の行、色、行番号、差分のコマ）。実ファイルには触れない。見せるのは、サーバーが渡す本文（`withText`）
- 起動時までのコマは、一覧に載せるだけで、見せない。起動後に追記されたコマから見せる。テープの `external` のコマは出るが、最後の差分（`final`）は出ない（記録済みのテープを開くときにする比較のため）
- **最新を追っている間**は、新しいコマをすぐ見せる。下のバーに「● LIVE」。コマが続けて届いても追いかける
- **コマ送りで古いコマに戻ると**、画面は動かさず、新しいコマの数だけ数える。下のバーに「LIVE に戻る（新着 N）」（橙の背景）が出る。押すと最新へ移り、また追いかける
- 別のテープに移ったら、一覧を作り直して、先頭から見せる

### 8. 表示するコマの種類

- 種類 **look・edit・external・failure** を、それぞれ ON/OFF できる。始めは look・edit・external が ON、**failure が OFF**。`final`（録画後の差分）は external に、`replace` と `new` は edit に連れる
- 操作一覧の右上の**漏斗ボタン**（とコマンド `srwr: 表示するコマを選ぶ`）で、4つの種類の複数選択が開く。決めると、選んだ種類でテープを開き直し（[protocol_ja.md](protocol_ja.md)）、今のコマに一番近いコマ（記録の順で）へ移る。ライブは、開き直して最新を追う
- 番号は、表示しているものの 1、2、3…。なので、一覧の番号 = 下のバーの位置、が今のまま成り立つ
- 一覧の見出しの下に、隠している数を出す：`Hiding: failure (2)`（日本語の画面は `隠している：failure (2)`）。ライブでは、届くコマに合わせて数が変わる
- OFF の種類は、一覧にもコマ送りにも出ない。ライブの「LIVE に戻る（新着 N）」は、**表示している種類だけ**を数える
- 何も表示しないときは「表示するコマがありません」と出す
- 選んだ内容は保存しない：拡張が動いている間だけ覚え、開き直すとデフォルトに戻る。srwr は、そのための設定を足さない

### 7. テープ一覧

- 「テープを開く」で、操作を1つ以上持つテープを、新しい順に出す（その機械の時間帯の開始時刻を秒まで、続けて操作数とファイル、その下にテープのファイル名）。選ぶと1コマ目から見せる

## コマンドと設定

| コマンド | 動き |
|---|---|
| srwr: テープを開く（`srwr.openTape`） | 一覧から選んで開く |
| srwr: 閉じる（テープ・ライブ）（`srwr.closeTape`） | 録画かライブ、開いているほうを閉じる |
| srwr: 進む／戻る（`srwr.stepForward`・`srwr.stepBack`） | コマ送り（ライブでも効く） |
| srwr: ライブ視聴を開始／停止（`srwr.liveStart`・`srwr.liveStop`） | |
| srwr: LIVE に戻る（`srwr.liveLatest`） | 最新へ移り、また追う |
| srwr: 表示するコマを選ぶ（`srwr.chooseKinds`） | look・edit・external・failure の種類を ON/OFF |
| `srwr.goto` | 内部用（操作一覧のクリック）。コマンドパレットには出さない |

| 設定 | 既定 | 意味 |
|---|---|---|
| `srwr.path` | `srwr` | `srwr` のバイナリの場所（開発では環境変数 `SRWR_PATH`） |

## 動きの仕組み（作る人向け）

- コマの列は、表示サーバーが作る（[protocol.md](protocol_ja.md)）。拡張は描くだけ
- 範囲・理由の行・差分の行の色は、`TextEditorDecorationType`。標準の行番号は、`editor.options.lineNumbers` を切り替え、自前の番号は装飾の `before`（`contentText`）で出す
- 画面の文言は `vscode.env.language`（`src/lang.ts`）で選ぶ。`package.json` の名前は `package.nls.json`（英語）と `package.nls.ja.json`（日本語）の `%キー%`
- 設計の判断は [decisions.md](../design/decisions_ja.md)
