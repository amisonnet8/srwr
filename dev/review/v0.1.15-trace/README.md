# v0.1.15：srwr trace（UIゲート）

見る：`index.html`（画像は埋め込み）。

## ポイント
- 作るもの：`git show`・`git diff`・`git log -p` の出力（統一差分のテキスト）を渡すと、追加行を作ったテープの操作（テープID・seq・時刻・why）を出す。`mtqg format` と同じ形（ファイル、なければ標準入力）。
- srwr と git は独立（git を動かさない・hook を足さない）。読み取りだけ。テープ・プロトコル・VSCode と Vim の画面は変えない。
- 引き方：差分の追加行の連なりと、テープの `edit`・`new` の新しい行の連なりを内容で突き合わせる。同じ行が複数の操作にあるときは新しい方。1行だけの短い一致は結びつけない。
- 結びつかない行は「テープに無い」と数で言う。
- 出力のテープID は `srwr view <テープ>` で開ける。切り出しテープ（`--as-tape`）は次の版。

## 従う確定デザイン
CLI の既存の出力（`srwr tapes`・`srwr tapes check`）の書き方（2字下げ、ファイルごとの見出し）。
