new ゲート：複数ファイルの文字列置換 sub の画面

確定デザイン（docs/reference/vscode.md・vim.md）は、ここに書いた所だけ変えます。画像は dark と light の両方です。例：oldName を newName にする。a.go に2か所、b.go に1か所。

作るもの

  • 新しい MCP ツール new（file・content・why）。既にあるファイルにはエラー file_exists
  • 足りない親ディレクトリは作る。記録しないファイル・作業場の外は作らない
  • 画面：replace のコマと同じ1枚のエディタ（ファイル全体が薄い橙、1行目の上に橙の理由の行）。一覧は new config.go:1-5（橙の丸）。失敗は赤
  • 既存の利用者は srwr init をもう一度実行する（新ツールの許可）

新しく決めること（推奨が先頭）

  1. 新しいファイルのコマ：1枚のエディタ（推奨）／左が空の左右の差分
  2. 親ディレクトリ：作る（推奨）／作らずエラー
  3. 返事：selection・startLine・endLine だけ（推奨）
