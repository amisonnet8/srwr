# R6 UIゲート：確認ページ（qsoku ui-check）

見るのは `index.html`（画像を埋め込んだ1ファイル。ブラウザで直接開ける）。

- **新しいのは確認ページだけ。** エディタの画面は変えない
- `qsoku ui-check` を1回動かすと `ui-check-result/latest/index.html` ができる。上から：まとめ、自動の検証の表、基準と違うコマ（左＝基準、右＝今、違うところに赤枠）、人間が判断すること
- 変更が無ければ大きく「違いなし」。新しいコマ（長い理由など、基準が無いもの）は「新しいコマ」として出す
- 決めてほしいこと（推奨はどれも A）
  1. 確認ページの見た目：A 見本のとおり（簡素な1枚）
  2. OK／NG の付け方：A ページは見るだけ。人間がチャットで答え、AI が `qsoku ui-accept` で記録し、OK なら基準を差し替える／B ページにボタン（小さなサーバーが要る）
  3. VSCode の画面の描き方：A VSCode 風の簡素な SVG／B 文言の表だけ
- 見本の図は、承認済みの画像（`handoff/design/images/`）の複製に、色を1か所だけ変えたもの
