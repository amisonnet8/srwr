sub ゲート：複数ファイルの文字列置換 sub の画面

確定デザイン（docs/reference/vscode.md・vim.md）は、ここに書いた所だけ変えます。画像は dark と light の両方です。例：oldName を newName にする。a.go に2か所、b.go に1か所。

作るもの

  • 新しい MCP ツール sub：文字列を、複数ファイルで置き換える。当たりの数が合わなければ、何も変えない
  • 画面：ファイルごとに1コマ。external と同じ左右の差分（左＝前・青、右＝後・橙）
  • 理由は、タブとエディタの間の橙の帯。VSCode は右の先頭に理由の行、左の先頭に同じ色の空の行（文字は右の中央）。Vim は2つの窓の上に帯
  • 一覧は sub a.go (2 hits) の1行。数が合わない失敗は ✖ sub failed (count_mismatch)（赤）
