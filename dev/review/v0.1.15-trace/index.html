v0.1.15：srwr trace（コミットの差分から、行を作った操作と理由を引く）

  • 作るもの：git show・git diff・git log -p の出力（統一差分を含むテキスト）を渡すと、追加された行を作ったテープの操作（テープID・seq・時刻・why）を出す。mtqg format と同じ形（ファイル、なければ標準入力）。
  • srwr と git は独立：srwr は git を動かさない・hook を足さない。テープも差分の形も変えない。読み取りだけ。
  • 引き方：差分の追加行の連なりと、テープの edit・new の新しい行の連なりを突き合わせる（時刻でなく内容）。同じ行が複数の操作にあるときは新しい操作。1行だけの短い一致（} など）は結びつけない。
  • 結びつかない行は「テープに無い」と数で言う（人が書いた・記録しないファイル・テープを消した、など）。
  • 見直し：出力のテープID は srwr view <テープ> でそのまま開ける。切り出して再生できるテープにする --as-tape は次の版。
  • 画面（VSCode・Vim）・テープ・プロトコルは変えない。
  • 了承してほしいこと：(a) 出力の形（下の4つ） (b) --mark の形 (c) 「テープに無い」の言い方

1. 既定の出力（英語）

2. 日本語（SRWR_LANG=ja）

3. テープに無い行があるとき（複数コミット）

4. --mark（差分をそのまま出し、hunk の次に理由を足す）
