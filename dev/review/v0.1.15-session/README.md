# v0.1.15：セッション管理（UIゲート）

見る：`index.html`（画像は埋め込み）。

## ポイント
- 作るもの：MCP の新しいツール `session {title, why}`。AI が「別の作業を始める」とき、題と理由を付けて新しいテープを始める。呼ばなければ今のまま（30分で自動で区切る）。ツールは4つになる。
- 題と理由は、新しいテープの header に書く（今のテープに後から付けない）。題なしのテープは今と同じ。区切りは作業場全体に効く。
- 見せるのは**一覧だけ**：`srwr tapes`・Vim のテープ一覧・VSCode のテープ選び。再生の画面（コマ・ステータス行・バー）は変えない。プロトコルは TapeInfo に `title`・`why` を足すだけ（`protocolVersion` 3 のまま）。
- 題のないテープは、3つとも今と同じ見た目（基準は変わらない）。

## 従う確定デザイン
一覧の既存の列・色・並び（`srwr tapes`、Vim の `srwr://tapes`、VSCode の QuickPick）。足すのは題の1か所だけ。

## 新しく決めること（推奨はこの案）
- `srwr tapes`：題のあるテープの行の下に、4字下げで題を1行（画像 cli）
- Vim：行の最後（テープID の後ろ）に列を足して題（画像 vim）
- VSCode：選択肢の見出し（label）を「時刻  題」（画像 vscode）。説明・詳細は今のまま
- 理由（why）は一覧に出さない（テープを開いた header に残るだけ）

上の3つの見せ方。了承されてから実装する。
